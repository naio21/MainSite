Aplicação web desenvolvida como vitrine institucional e showcase de produto, com foco em experiência do usuário, organização de código e preparação para ambiente real de negócio.

## Visão geral

Este repositório representa mais do que um site institucional. Ele demonstra a capacidade de transformar uma necessidade de negócio em uma solução digital moderna, clara e funcional.

A proposta combina apresentação de marca, divulgação de produto SaaS, autenticação de usuários, proteção de áreas privadas e geração estática para entrega com boa performance.

## Status do projeto

Projeto funcional, em evolução contínua, com base sólida para expansão comercial e técnica. O frontend público está neste repositório, enquanto o backend em C# permanece privado por decisão estratégica.

## Para recrutadores

Se você busca um profissional capaz de unir **visão de produto**, **execução técnica** e **preocupação com usabilidade**, este projeto mostra na prática competências como:

- estruturação de aplicação com Vue 3 e arquitetura organizada
- criação de páginas institucionais com foco em comunicação e conversão
- implementação de autenticação e proteção de rotas privadas
- cuidado com segurança de conteúdo sensível no front-end publicado
- preparação para deploy e publicação estática com Vite SSG
- integração com serviços externos via API

## O que este projeto demonstra

### Produto com propósito real
A aplicação apresenta a ibpsys e o produto Watch SR, uma solução voltada à gestão de Ordens de Serviço para relojoeiros.

### Pensamento de negócio
O projeto não foi construído apenas como exercício técnico. Ele foi pensado para comunicar valor, apoiar aquisição de usuários e servir como base para evolução comercial do produto.

### Boa base de engenharia
A estrutura contempla rotas, páginas públicas e autenticadas, serviços separados, build otimizada e organização suficiente para escalar a aplicação com segurança.

## Principais funcionalidades

## Stack utilizada

### Frontend
- Vue 3
- Vite
- Vite SSG
- Vue Router
- Axios
- CSS

### Backend
A API que atende esta aplicação é desenvolvida em **C#**, com regras de negócio e endpoints mantidos em um repositório privado. Por opção estratégica, o código do backend não está público, mas a integração faz parte da arquitetura completa da solução.

## Sobre o Watch SR

O **Watch SR** é uma solução SaaS criada para apoiar profissionais relojoeiros no controle de sua operação diária.

Entre os recursos e benefícios do produto, destacam-se:

- cadastro e gestão de clientes
- acompanhamento de ordens de serviço
- controle de status e andamento dos atendimentos
- organização de prazos e previsões
- melhoria do fluxo operacional

## Execução local

### Pré-requisitos

- Node.js
- npm

### Comandos

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
```

Visualização local da versão final:

```bash
npm run preview
```
